FOOTBALL ODDS SCANNER — ИНСТРУКЦИЯ

Что это:
Мобильная веб-программа на FastAPI. Она получает доступные предматчевые коэффициенты 1X2 через API-Football, показывает букмекерские котировки, лучшие цены по каждому исходу и проверяет теоретический арбитраж между букмекерами.

ВАЖНО:
- API-ключ НЕ вставлять в код, HTML, GitHub или этот архив.
- Ключ хранить только в Render -> сервис -> Environment как API_FOOTBALL_KEY.
- Не отправлять ключ в чат.
- Реальные ставки программа не размещает.
- Арбитражный расчёт теоретический: возможны лимиты, задержки, изменения коэффициентов и отклонения ставок.

РАЗМЕЩЕНИЕ:
1. Создать аккаунт GitHub: https://github.com/signup
2. Создать новый репозиторий, например football-odds-scanner.
3. Распаковать архив и загрузить все файлы и папку templates в репозиторий.
4. Создать аккаунт Render: https://render.com/register
5. В Render выбрать New -> Blueprint и подключить GitHub-репозиторий.
6. Render обнаружит render.yaml и создаст Web Service.
7. Открыть сервис -> Environment -> Add Environment Variable:
   Key: API_FOOTBALL_KEY
   Value: (вставить свой API-ключ)
8. Сохранить и дождаться Deploy.
9. Открыть URL сервиса вида https://имя-сервиса.onrender.com на телефоне.

ПРОВЕРКА:
Открой https://имя-сервиса.onrender.com/health
Ожидаемый ответ:
{"ok":true,"api_key_configured":true}

Затем открой главную страницу и нажми «Загрузить коэффициенты».

ПРИМЕЧАНИЕ:
Наличие odds зависит от подписки, даты, лиги и букмекеров, доступных в аккаунте API-Football. Бесплатные web services Render могут засыпать после периода бездействия и запускаться с задержкой при следующем открытии.
